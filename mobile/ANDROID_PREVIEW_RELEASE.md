# DOCU Android preview v0.1.2

This preview restores Scan-first navigation and a reachable Tools tab. It also
includes the existing page editing, merge, compression, image-to-PDF, and
document sharing flows.

Download `DOCU-Android-universal-v0.1.2-navigation-debug.apk` from this GitHub
Release and open it on an Android phone to install. Android may require you to
allow installs from the app used to open the APK.

This is a debug-signed preview with package ID `com.yourname.docapp`. It can
update only installations signed with the same project debug key. The eventual
release-signed package will require uninstalling this preview first. Back up
any documents you want to keep before uninstalling.

SHA-256: `87cd04495ad211b10e12254b476f0d6f804db325f0ba5cc7f1ed2868cc14b154`

For the signed GitHub and Google Play build, follow [PLAY_RELEASE.md](PLAY_RELEASE.md).
