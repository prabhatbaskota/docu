# PDF Worker (Streamlit)

This is the original Streamlit PDF Worker. It is independent of the Flutter
[mobile](../mobile/) and [desktop](../desktop/) apps.

From this directory, install the Python dependencies and launch the app:

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The Windows installer is built from `desktop/`, not from this application.
