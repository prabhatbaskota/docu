## `mobile/README.md`

```md
# docu mobile

Local-first Android and iOS document scanner and PDF toolkit. No accounts, ads or analytics.

## Features

- Manual camera capture with stable live outlines, perspective correction, sequential review and durable draft recovery
- ID/card front and back on one A4 page at physical ID-1 or passport size
- Page editing, reorder, replace/insert, merge, favorites, folders and search
- Optimal or target-size compression with cancellation and preserved originals
- Offline English/Devanagari OCR, full-text search, text export and searchable PDF export

## Setup

Use Flutter 3.38+ (Dart 3.10+). Run from mobile/:

```powershell
flutter pub get --enforce-lockfile
flutter analyze
flutter test
flutter run
```

Native OpenCV builds require the platform compiler toolchain. On Android install
the Android SDK, NDK, CMake and Ninja. Android minSdk is 24.

## Export a local Android APK

Follow [the build handoff](../scripts/ANDROID-BUILD.md). After resolving mobile
dependencies, run from the repository root on Windows:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android-apk.ps1
```

The helper exposes the SDK/NDK to OpenCV's native hook, verifies the APK signature
and exports the universal debug APK and checksum to release/ at the repository root.

## `scripts/build-android-apk.ps1`

```ps1
[CmdletBinding()]
param([switch]$PrepareOnly)

$ErrorActionPreference = 'Stop'
$projectRoot = Split-Path -Parent $PSScriptRoot
$mobileRoot = Join-Path $projectRoot 'mobile'
$localProperties = @{}
$propertiesFile = Join-Path $mobileRoot 'android/local.properties'
if (Test-Path -LiteralPath $propertiesFile) {
    foreach ($line in Get-Content -LiteralPath $propertiesFile) {
        if ($line -match '^([^#=]+)=(.*)$') {
            $localProperties[$matches[1]] = $matches[2].Replace('\\', '\').Replace('\:', ':')
        }
    }
}
function Get-LatestSdkDirectory([string]$ParentDirectory) {
    $directory = Get-ChildItem -LiteralPath $ParentDirectory -Directory |
        Where-Object { $_.Name -match '^\d+(\.\d+)+$' } |
        Sort-Object { [version]$_.Name } -Descending | Select-Object -First 1
    if (-not $directory) { throw "No installed tools found in $ParentDirectory" }
    return $directory.FullName
}
$sdkRoot = $env:ANDROID_HOME
if (-not $sdkRoot) { $sdkRoot = $env:ANDROID_SDK_ROOT }
if (-not $sdkRoot) { $sdkRoot = $localProperties['sdk.dir'] }
if (-not $sdkRoot -or -not (Test-Path -LiteralPath $sdkRoot -PathType Container)) {
    throw 'Set ANDROID_HOME or sdk.dir in mobile/android/local.properties to the installed Android SDK.'
}
$sdkRoot = (Resolve-Path -LiteralPath $sdkRoot).Path
$ndkRoot = $env:ANDROID_NDK_HOME
if (-not $ndkRoot) { $ndkRoot = Get-LatestSdkDirectory (Join-Path $sdkRoot 'ndk') }
$cmakeBin = Join-Path (Get-LatestSdkDirectory (Join-Path $sdkRoot 'cmake')) 'bin'
$buildTools = Get-LatestSdkDirectory (Join-Path $sdkRoot 'build-tools')
foreach ($tool in @((Join-Path $ndkRoot 'build/cmake/android.toolchain.cmake'),
                    (Join-Path $cmakeBin 'cmake.exe'), (Join-Path $cmakeBin 'ninja.exe'),
                    (Join-Path $buildTools 'apksigner.bat'))) {
    if (-not (Test-Path -LiteralPath $tool -PathType Leaf)) { throw "Required Android tool is missing: $tool" }
}
$flutter = (Get-Command flutter -ErrorAction Stop).Source
if ($PrepareOnly) {
    [pscustomobject]@{ AndroidSdk = $sdkRoot; AndroidNdk = $ndkRoot; CMake = $cmakeBin; BuildTools = $buildTools; Flutter = $flutter }
    return
}
$previousEnvironment = @{}
foreach ($name in @('ANDROID_HOME', 'ANDROID_SDK_ROOT', 'ANDROID_NDK_HOME', 'PATH')) {
    $previousEnvironment[$name] = [Environment]::GetEnvironmentVariable($name, 'Process')
}
$previousLocation = Get-Location
try {
    # Native Dart hooks do not read Android's local.properties.
    $env:ANDROID_HOME = $sdkRoot
    $env:ANDROID_SDK_ROOT = $sdkRoot
    $env:ANDROID_NDK_HOME = $ndkRoot
    $env:PATH = "$cmakeBin;$buildTools;$ndkRoot;$env:PATH"
    Set-Location -LiteralPath $mobileRoot
    & $flutter build apk --debug --no-pub
    if ($LASTEXITCODE -ne 0) { throw "Flutter APK build failed with exit code $LASTEXITCODE" }
    $apk = Join-Path $mobileRoot 'build/app/outputs/flutter-apk/app-debug.apk'
    if (-not (Test-Path -LiteralPath $apk -PathType Leaf)) { throw "Flutter did not create $apk" }
    & (Join-Path $buildTools 'apksigner.bat') verify --verbose $apk
    if ($LASTEXITCODE -ne 0) { throw 'APK signature verification failed.' }
    $version = [regex]::Match((Get-Content (Join-Path $mobileRoot 'pubspec.yaml') -Raw), '(?m)^version:\s*(\S+)').Groups[1].Value.Split('+')[0]
    $exportDirectory = Join-Path $projectRoot 'release'
    New-Item -ItemType Directory -Path $exportDirectory -Force | Out-Null
    $exportPath = Join-Path $exportDirectory "DOCU-Android-universal-v$version-features-debug.apk"
    Copy-Item -LiteralPath $apk -Destination $exportPath -Force
    $digest = (Get-FileHash -LiteralPath $exportPath -Algorithm SHA256).Hash.ToLowerInvariant()
    "$digest  $([IO.Path]::GetFileName($exportPath))" | Set-Content -LiteralPath "$exportPath.sha256" -Encoding Ascii
    Write-Output "Exported $exportPath"
} finally {
    Set-Location -LiteralPath $previousLocation.Path
    foreach ($name in $previousEnvironment.Keys) {
        [Environment]::SetEnvironmentVariable($name, $previousEnvironment[$name], 'Process')
    }
}
```

## `scripts/ANDROID-BUILD.md`

```md
# Android APK build and export

Run these commands on a Windows machine with Flutter 3.38+ (Dart 3.10+),
Java 17, Android SDK platform/build-tools 36, the NDK requested by Flutter,
and Android SDK CMake/Ninja installed. Run Flutter commands from `mobile/`.

```powershell
Set-Location mobile
flutter pub get
Set-Location ..
powershell -File scripts/build-android-apk.ps1 -PrepareOnly
powershell -File scripts/build-android-apk.ps1
```

`-PrepareOnly` checks installed tool paths without compiling. The helper reads
`ANDROID_HOME`, `ANDROID_SDK_ROOT`, or `mobile/android/local.properties` for
the SDK. You can set `ANDROID_NDK_HOME` to choose a specific installed NDK;
otherwise it uses the newest installed numeric version. It discovers Android
SDK CMake, Ninja and build-tools, then passes the SDK/NDK paths explicitly to
Flutter's native hooks. Flutter finding the SDK from `local.properties` alone
is insufficient for OpenCV's hook on this setup.

The helper builds a universal debug APK, checks its Android signature and
exports it with a SHA-256 checksum to:

```text
release/DOCU-Android-universal-v0.1.2-features-debug.apk
release/DOCU-Android-universal-v0.1.2-features-debug.apk.sha256
```

The version in the filename follows `mobile/pubspec.yaml`. This is a signed
local preview, not a Google Play release. Release signing and application ID
configuration are documented in `mobile/PLAY_RELEASE.md`. The helper expects
`flutter pub get` to have resolved dependencies before building.
